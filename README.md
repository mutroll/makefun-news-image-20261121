A poster that sums up the world news of Saturday 21 November 2026 in one image: a Russian missile crashes in Poland, Wall Street slides into correction, the World Court rules Myanmar committed genocide, a magnitude 6.8 quake shakes Peru, Rikers Island is set to close by 2032, and the UK and EU seal a post-Brexit reset.

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py` — it writes a deterministic 1024×1024 PNG to `out/entry.png`, using only the Python standard library.
